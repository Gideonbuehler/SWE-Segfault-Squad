# Install/Build/Run Instructions

## Steps without docker:

1. Clone from github repository

2. Open two terminals (or a terminal in each IDE)

3. Navigate to backend folder and frontend folder on their respective terminals

4. On the backend terminal, run ./gradlew run

5. On the frontend terminal, run npm run dev

## Steps with docker: 

1. Clone from github repository

2. Open a terminal and navigate to the project folder
   
4. Run 'docker compose up -d --build'
